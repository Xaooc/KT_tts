# Проверка в TTS: чек-лист

Загрузите «KT24 The Killzone — русский перевод» заново (Games → Save & Load). Для проверки за двоих можно сидеть
одному и переключать цвет места. Отмечайте пункты. Если что-то не так, напишите номер пункта и что видно на экране.

1. **Загрузка.** Слева виден узкий рельс с вкладками. Ошибок в чате нет. Табло внизу, шахматные часы и лог на месте.
2. **Рельс → «Ход».** Центр раскрылся. Текст нигде не обрезан и не налезает. В шапке раунд, фаза и обе стороны с CP/VP.
3. **Запуск партии** (ведущий): раунд, этап и кто ходит выбираются, «Начать партию» срабатывает.
4. **«Отряд» → «+ Добавить все мои со стола».** Появились ваши модели. Модели из мешков не попали. Клик по карточке
   подсвечивает модель.
5. **Активация.** «Ход ›» у готового оперативника. Видны характеристики, AP, оружие и действия.
   Перемещение → внизу сообщение «Отменить». Отмена возвращает AP.
6. **Стрельба.** «Стрельба» → вкладка «Уловки» показывает подходящие уловки → «Завершить стрельбу» → «Завершить
   активацию». Ход перешёл к сопернику, у соперника обновилась шапка.
7. **Уловка с CP.** «Применить» списал CP на табло. «Отменить» вернул их.
8. **Прокрутка.** Длинный список (уловки, справочник) прокручивается колесом. После клика прокрутка не прыгает
   в начало без нужды.
9. **R-карточка.** Выберите модель, нажмите R. Справа карточка. Клик по оружию бросает кубики. «?» у трейта открывает
   определение в центре. Карточку можно перетащить. «×» закрывает её.
10. **Справка.** Поиск «реаним» (или любое слово) находит правила. Статья читается целиком. Термин открывается поверх
    статьи и закрывается.
11. **Враг.** Видны модели соперника с ранами. Его уловки и правила читаются.
12. **Журнал.** Видны события раунда. «Счёт по раундам» совпадает с табло.
13. **Хоткеи** (Options → Game Keys): «Центр KT: открыть / свернуть» работает.
14. **Сохранение.** Сохраните игру, загрузите снова: раунд, отряд и CP на месте, центр открывается.
15. **Второй игрок / другой цвет.** Центр Синего независим от Красного. Кнопки чужого центра не видны.

Особенно важно: пункты 2, 8 и 9. Именно там TTS может отображать вёрстку иначе, чем предпросмотр.
